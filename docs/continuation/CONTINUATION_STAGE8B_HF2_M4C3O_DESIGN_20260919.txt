CONCRETE STRUCTURAL DEFECTS REPRODUCED
The following were reproduced by a short disposable read-only probe against the exact post0018 source.

1. Determiner-led copular declarative
Input:
The lamp is on.

Current event inventory includes:
- false ditransitive active candidate:
  agent = the
  predicate_surface = lamp
  recipient_or_theme = is
  theme_or_patient = on
  ambiguity = ditransitive-role-order-candidate
- correct copular candidate:
  theme = the lamp
  attribute_or_identity = on
- false generic SVO candidate:
  agent = the
  predicate_surface = lamp
  patient_or_theme = is on

Therefore the known combined turn:
The lamp is on. Is the lamp on?
receives a fabricated event-role ambiguity even though the exact proposition query parser can otherwise represent the copular question.

2. Determiner-led active declarative
Input:
The teacher opened the door.

Current event inventory misreads:
agent = the
predicate_surface = teacher
and creates both a false ditransitive ambiguity and a false generic SVO candidate.

3. Direct object beginning with a determiner
Input:
Teacher opened the door.

Current generic SVO candidate is usable, but the ditransitive regex also creates a false ditransitive ambiguity because the middle surface becomes:
the

A determiner must not itself become a recipient/theme candidate.

4. Copular yes/no inversion
Input:
Is lamp on?

Current event inventory can create an active-SVO-like candidate:
agent = is
predicate_surface = lamp
patient_or_theme = on

This is a clause-shape artifact, not a truth claim.
The question already has explicit question-family/QUD representation.

5. Passive control
Input:
The book was placed by Mira.

Current passive candidate is clean and must remain unchanged.

6. Genuine double-object control
Input:
Teacher gave Omar the book.

Current grammar preserves ditransitive role alternatives.
M4C3O must not collapse genuine structural ambiguity by semantic guessing or verb tables.

ROOT CAUSE CLASSIFICATION
The current candidate regexes treat whitespace tokens too directly as constituent boundaries.

In particular:
- a leading determiner can be captured as the whole subject while the noun is captured as the apparent verb;
- a direct-object determiner can be captured as a standalone middle argument;
- auxiliary-initial copular questions can be interpreted as ordinary active declaratives.

This creates false grammatical ambiguity that later proof/resolution layers correctly refuse to hide.

The downstream proof gate is therefore doing the safe thing.
M4C3O should repair the upstream candidate inventory rather than weaken proof/ambiguity gating.

DESIGN CONSTRAINTS
A safe correction must remain transparent and structural.

It may use:
- existing determiner/function-word sets;
- finite surface clause shape;
- already-existing copular auxiliary recognition;
- noun-phrase boundary grouping sufficient to prevent determiners from occupying verb/role slots.

It must NOT use:
- semantic verb-class tables to decide truth;
- candidate ranking by lexical meaning;
- LLM inference;
- hidden answer selection;
- authored preference weights;
- parser labels as native speech-act choice;
- canned clarification fallback.

PROPOSED BOUNDED BEHAVIOR
1. Recognize a transparent copular declarative surface before active ditransitive/SVO fallback can misconsume a determiner-led subject.
2. Do not emit a generic active candidate that is merely a second incompatible parse of the same transparently copular clause.
3. Prevent a determiner from being emitted as an independent recipient/theme/patient role candidate.
4. Preserve a determiner-bearing noun phrase as a grammatical constituent for active SVO candidate formation.
5. Prevent auxiliary-initial copular yes/no questions from generating a fake active-declarative event candidate solely from token order.
6. Preserve real passive handling.
7. Preserve genuine double-object ambiguity as alternatives when the surface actually supplies distinct non-function constituents.
8. Keep all surviving candidates zero-authority grammatical inventory only.
