CURRENT LANGUAGE_DIALOGUE MECHANISM
src/noeron/language_dialogue.py currently:
1. computes _reference_candidates() over the entire ingress BEFORE sentence splitting/event extraction;
2. supplies only state.dialogue.recent_referents from PRIOR admitted turns plus legacy Stage-6 discourse fallback;
3. therefore cannot use event mentions from an earlier sentence in the SAME ingress;
4. persists referent_mentions() from event roles into a flat recent-referent list;
5. for third-person/deictic non-person reference, _reference_candidates() uses recent non-person mentions without grammatical-role filtering;
6. for person-like pronouns it uses recent kind in {person, unknown};
7. copular event candidates record roles:
   theme=<subject surface>
   attribute_or_identity=<predicate complement surface>
   both are currently persisted with kind=unknown.
