WHAT M4C3D ADDS
M4C3D introduces typed current-turn alternative content while retaining zero truth, answer, ranking, reference-resolution, speech-act, relationship, source-write, and deployment authority.

NativeResolutionContent now records a typed kind:
- reference-alternatives
- event-role-alternatives
- qud-alternatives
- proposition-alternatives
- proof-alternatives
- existing-native-question

Each serialized unit explicitly carries false authority flags for semantic truth, answer authority, candidate ranking, speech-act selection, and reference resolution.

Reference alternatives remain grounded only in explicit current-turn parser reference-candidate sets with matching token/source provenance.
Event-role clarification content is admitted only from explicit parser-side event_role_alternatives with matching event source rows and grammatical-event-role-candidate-only authority. Existing diagnostic ambiguity labels alone remain insufficient.

M4C3D additionally inventories, without granting speech-act eligibility:
- QUD alternative sets only when an explicit current-turn question surface is scoped by an already-explicit unresolved candidate set;
- proposition alternatives only when existing reasoning reports multiple proof-supported answers with no forced choice;
- proof alternatives only when multiple existing direct derivation steps support the same exact conclusion, preserved as canonical JSON rather than summarized or invented.

native_current_turn_alternative_sources collects these typed unselected alternatives. It never resolves a reference or role, ranks candidates, creates a proposition, or chooses a speech act.

native_resolution_sources remains the execution-eligible content boundary. In M4C3D it admits explicit reference and explicit parser-side event-role candidate sets only. QUD/proposition/proof inventory remains separate and therefore cannot silently manufacture clarify eligibility.

resolution_content_units maps only allowed typed content into NativeResolutionContent. Existing native-language realization exposes unresolved option strings using already-admitted source content and punctuation; it still does not assert or select an option.

The M4C3D exact-anchor intent audit explicitly reports false authority for:
semantic_truth, answer, candidate_ranking, cognitive_memory, relationship, source_write_runtime, deployment, and speech_act.
