WHAT M4C3F IMPLEMENTS
1. Adds a receipt type distinct from the clarify/ask ASGI transport receipt:
   NonContentResolutionExecutionReceipt.
2. It is valid only for genuinely native-selected defer/remain-silent.
3. channel=local-runtime-noncontent.
4. status=local-noncontent-action-committed.
5. defer effect:
   defer-current-turn-resolution.
6. remain-silent effect:
   close-current-turn-without-outward-realization.
7. The receipt records only local runtime execution provenance: current event, turn, selected action, effect, pre-knot digest, pre-residual, completion time.
8. It hard-codes false for:
   content_emitted,
   outward_transport_performed,
   peer_delivery_confirmed,
   peer_read_confirmed,
   peer_understanding_confirmed,
   peer_reply_causation_confirmed.
9. No empty message is emitted merely to manufacture a receipt.
10. The independent expression selector is not invoked for this non-content action and no expression pending state is created.
11. A client/serialized imitation cannot mark execution; the mark requires the identical in-process receipt capability during the trusted local transaction.
12. Owner-command/operator-override/endogenous/nonconversational events cannot be converted into native non-content execution through this path.
13. The receipt itself never trains speech-act consequence geometry.
14. Later learning still requires a distinct later nonempty conversational USER_MESSAGE, correct temporal ordering, matching pre-knot/pre-residual provenance, native security admissibility, and the existing nonworsening residual gate.
15. Persistence failure rolls back speech-act state and the security checkpoint.
16. Existing clarify/ask authenticated-owner Room HTTP transport and ASGI send-completion semantics are unchanged.

RECEIPT MEANING
For defer, the local runtime commits the selected decision not to outwardly resolve the current turn now. This is not a scheduled future task and creates no promise of a later message.

For remain-silent, the local runtime commits the selected no-outward-realization action for the current turn.

Neither effect is evidence that any peer received, displayed, read, understood, or replied to anything. No content was sent.
