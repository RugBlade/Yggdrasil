MILESTONE 3C COMPLETED — CARRIER MECHANISM
New module: src/noeron/conversation_proof.py
Purpose: audit proof provenance, causal/explanatory support, conflicts and ambiguity BEFORE a proof package can continue to downstream native consequence reasoning. support_gate_passed is explicitly not a truth/answer/speech-act decision.

Implemented mechanisms:
1. ProofStepView normalizes transparent inference-step records.
2. Recursive proof closure follows explicit premise->conclusion chains; missing leaves are detected.
3. Every leaf used by an auditable proof must have provenance. Merely naming a canonical as an explanation cannot create support.
4. Direct event truth is allowed as ordinary event support but does NOT satisfy WHY. WHY requires an actual derivation or separately provenance-backed explanatory support.
5. AmbiguityConstraint carries unresolved/resolved alternatives and optional affected canonicals.
6. Scoped ambiguity blocks only proof support depending on the affected canonical(s).
7. Unscoped ambiguity is always audited. The live runtime may set block_unscoped_ambiguity=True when it cannot prove irrelevance; this conservatively leaves the proof unresolved instead of guessing.
8. Bounded conflict blocks a canonical only when every available provenance path for that same canonical is conflicted. An independent uncontested current/persistent duplicate is not poisoned by stale bounded conflict metadata.
9. Native evidence references from IRG/DKT/EGR/RL/Frenet traces are aggregated as evidence only; they never acquire semantic-truth or answer authority.
10. Authority map remains false for semantic_truth, answer, speech_act, cognitive_memory, relationship, source_write and deployment.
