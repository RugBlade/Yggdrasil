WHAT 0015 ADDS

1. NativeAudioTransportReceipt
A typed zero-authority transport/provenance record binds:
- native presentation id;
- audio artifact id;
- native-text SHA256;
- audio SHA256;
- artifact byte size;
- channel=authenticated-owner-room-audio-http;
- status=asgi-audio-response-sent;
- HTTP status;
- response byte count;
- Content-Range where applicable;
- ASGI pathsend usage;
- whether one HTTP 200 response carried exactly the full artifact size.

The following stay false:
playback_confirmed
peer_delivery_confirmed
peer_heard_confirmed
peer_understanding_confirmed
peer_reply_causation_confirmed
semantic_truth_authority
answer_authority
speech_act_choice_authority
preference_label_authority
cognitive_memory_authority
relationship_authority
source_write_authority
deployment_authority

2. Dedicated persistence/provenance
LocalEventStore receives a separate native_audio_transport_receipts table plus typed append/read/lookup helpers.
This is audit/provenance only.
It is not semantic memory and not cognitive retrieval authority.

3. Process-local preparation capability
A native-audio transport can be prepared only when:
- NativePresentationRecord points to the exact audio artifact;
- presentation/audio hashes match;
- direction is noeron-to-owner;
- media type is audio/*;
- the presentation records a genuine native voice choice.

The capability is in-process only, identity checked and single-use.
It is not serialized to saved NoeronState and cannot be manufactured by the client.

4. Trusted ASGI server-send boundary
The authenticated /room/files/{artifact_id} path wraps eligible native-audio artifacts in _NativeAudioRoomResponse.
Receipt creation happens only after the underlying ASGI send operation succeeds for the response terminal boundary.
Failed sends create no receipt.

5. Range responses remain partial
HTTP 206 byte-range responses preserve the exact response byte count and Content-Range.
They do not become a full-artifact claim.
complete_artifact_single_response is true only for HTTP 200 with the exact artifact byte count.

6. ASGI pathsend support
When the server uses http.response.pathsend, successful completion can record the exact artifact size as server-side transport evidence.
This still does not prove client playback/hearing.

7. No speech-act consequence learning
NativeAudioTransportReceipt is separate from ResolutionExecutionReceipt and NonContentResolutionExecutionReceipt.
Creating or fetching audio does not create a pending speech-act outcome, does not increment speech-act observations and does not train native consequence geometry.
