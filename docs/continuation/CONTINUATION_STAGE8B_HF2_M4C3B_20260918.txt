   These functions provide content availability, never action choice.
   The older calibration/structured preview helpers remain non-executing.

   independent of ask availability. Legacy helper calls remain compatible.
   Nonfinite/negative consequence distances now leave choice unresolved.
   No substitute metric, semantic score, utility weight or preference is added.

   propositions and question fields are empty and event provenance matches.
   Clarification uses only punctuation around the existing surfaces:
   focus: alternative / alternative?

   This is a SCHEMATIC native form, not fluent authored dialogue or a canned
   fallback. All alternatives stay visible and unresolved. English uses the
   existing deterministic observational egress unchanged.
