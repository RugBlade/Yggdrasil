THE THREE FAILURES ARE HARNESS FAILURES, NOT RUNTIME FAILURES
All three failures have the identical cause:
Playwright page.wait_for_function() with a string predicate internally evaluates JavaScript using eval().
The private Room CSP intentionally forbids unsafe-eval:
script-src 'self' 'unsafe-inline'

Chromium therefore raised:
EvalError: Refused to evaluate a string as JavaScript because 'unsafe-eval' is not an allowed source of script in the Content Security Policy.

Failed tests:
- stable audio element / lifecycle;
- network uncertainty retry;
- renewed-session playback closure rejection.

Each failed before evaluating the intended application invariant.
No assertion demonstrated incorrect Room runtime behavior.

Five real Chromium cases DID pass, including the four explicit 401/403/422/500 fail-fast/no-retry cases and product no-autoplay/programmatic-play enforcement.

HARNESS CORRECTION
Replace ONLY the CSP-incompatible page.wait_for_function() waits with a Python-side bounded polling helper that repeatedly uses page.eval_on_selector('audio', function).
eval_on_selector already executed successfully in the same real Chromium/CSP environment and does not require the page to allow unsafe-eval.

The correction must not:
- modify exact post0018 runtime source;
- weaken the Room CSP;
- add unsafe-eval;
- change application JavaScript;
- change auth/session semantics;
- change telemetry authority;
- create 0019.
