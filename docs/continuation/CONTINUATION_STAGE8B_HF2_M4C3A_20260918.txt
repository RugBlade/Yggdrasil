   eligible/content_status report content availability, never execution or choice.

   single current-turn snapshot from the direct cognition.response result.
4. The snapshot requires the admitted event ID, current conversational turn,
   response-kind thought, matching mathematical provenance source event, and
   exact current input SHA256. Endogenous, empty and nonconversational inputs
   cannot create it. It is invalidated at the start of every ingress, including
   rejected ingress; later event/turn changes invalidate its use.

   bounded working context, not cognitive memory, relationship or choice state.
   It is not consulted by the native speech-act selector.
6. Empty current native responses cannot resurrect old questions. Clarification
   preview preserves all supplied alternatives; it does not rank or resolve them.
7. Preview marks no pending action, increments no counters, trains no geometry,
   writes no thought/state/security checkpoint and authors no fallback sentence.
   Defer/remain-silent preview authors no semantic content and executes no act.

   refuses overwrite, and rejects the old calibration-preview origin.

   train. Their audit/pending state is preserved rather than silently deleted.
