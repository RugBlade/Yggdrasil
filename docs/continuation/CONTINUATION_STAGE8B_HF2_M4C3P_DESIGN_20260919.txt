B. CONCRETE DEFECT DEMONSTRATED ON EXACT POST0019
The transparent proposition parser treats a copular predicate complement as if it were a grammatical direct object when updating bounded discourse context.

Example 1:
"The lamp is on. Is it on?"
Current propositions:
lamp::is::on
Current query:
exact-proposition(on,is,on)
Current reference audit:
it -> on as query-subject
Current discourse state:
last_subject=lamp
last_direct_object=on
This is structurally malformed: "on" is the copular predicate complement, not a direct object/referent supplied by that clause.

Example 2:
"The lamp is on. Why is it on?"
Current query:
why-proposition(on,is,on)
Proof gate then sees no valid explanatory candidates for the malformed target.

Example 3:
"The lamp is red. What color is it?"
Current query subject:
red
Current reference audit:
it -> red
Again, the predicate complement is being used as a direct-object discourse antecedent.

Control:
"The book is on the table. Where is it?"
Current parser correctly resolves it -> book because the typed spatial-copular frame records table as an oblique, not a direct object.

ROOT CAUSE
In src/noeron/inference.py, the generic copular relation path calls grammatical discourse mention tracking with the predicate complement in the direct-object slot. Object pronouns then prefer last_direct_object over last_subject.
The failure therefore occurs BEFORE proof auditing and BEFORE native speech-act selection.
